# 날씨 복원 및 API 안정화 — 2026-09-08

## 이번 변경

- 완도와 모든 지역 페이지의 날씨 카드 표시 복원.
- 현재 날씨와 상세 예보·물때 조회 분리. 상세 창을 열 때 `/api/weather/details` 조회.
- 부분 실패 시 성공한 상세 정보는 표시하고 다시 시도 제공. 불완전한 상세 응답은 CDN에 캐시하지 않음.
- 공공 API GET 요청은 헤더뿐 아니라 본문 수신까지 요청당 8초 제한.
- 동일 URL·옵션의 진행 중 요청을 서버 인스턴스 안에서 공유. 완료·실패 후 제거.
- 기존 Next fetch 캐시 주기와 배편 결항 판정 로직 유지.
- 네트워크/HTTP 오류 때 날씨 격자·발표시각을 계속 바꾸어 재호출하지 않음. 정상 응답의 NO_DATA 대체 조회는 유지.
- 하늘 상태 조회 실패를 맑음으로 표시하지 않음.
- 브라우저 조회는 20초 제한 및 화면 정리 시 취소.

## 검증

- `node --test scripts/test-public-data-fetch.mjs`: 6개 통과. 외부 API 호출 없는 모의 검사.
- `npx tsc --noEmit --incremental false`: 통과.
- 실제 Vercel 배포 및 브라우저 통합 검증은 아직 하지 않음.

## 남은 범위 / 주의

- 8초는 개별 요청 제한이며, 기존 대체 조회·429 재시도가 있으면 전체 소요시간은 더 길 수 있음.
- Next의 기존 영속 fetch 캐시는 유지하지만 요청 공유·기존 마지막 정상 날씨 메모리는 인스턴스 간 공유되지 않음.
- 기존 관측 기준 날짜·시각은 그대로 표시. 이 변경이 공공 API 장애 자체를 해결하거나 데이터 최신성을 보장하지는 않음.
- `connection()`의 페이지 렌더 구조는 유지. 무조건 제거하면 빌드 시 외부 API 호출 문제가 재발할 수 있으므로 별도 검토.
- 배포 이후 첫 화면과 상세 창의 성공/부분실패/재시도 흐름, timeout 발생률 및 ISR 사용량을 확인해야 함.
