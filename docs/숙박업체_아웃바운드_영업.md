# 완도 숙박업소 아웃바운드 영업 (메일 템플릿)

> 특산물 업체용은 `특산물업체_아웃바운드_영업.md`. 이 문서는 **펜션·민박·스테이** 대상이다.
> 타겟 리스트는 `영업_타겟리스트_현지업체.md`의 P1~P4 (연락처 확인 필요 상태).

---

## 메일 작성 원칙 (확정)

1. **제안을 먼저, 이유는 나중에.** "하루 100명이 들어온다 → 광고 자리가 있다 → 하시겠습니까"를
   앞에 두고, 왜 숙박업소인지는 그 뒤에 설명한다. 배경 설명부터 시작하면 읽다가 닫는다.
2. **저자세 금지, 프로페셔널하게.** 부탁이 아니라 제안이다. 사정을 늘어놓지 않는다.
3. **장식 기호(■ · ▶) 쓰지 않는다.** 올드해 보인다. 문단으로만 나눈다.
4. **상호를 제목과 본문에 넣는다.** 일괄 발송 티가 나면 열람률이 급락한다.
5. **숫자는 있는 그대로.** 부풀리면 첫 리포트에서 바로 들통난다.

## 본 메일

### 제목 (셋 중 택1 — 상호는 반드시 치환)

```
청산도 배편을 확인하는 여행객에게 ○○펜션을 노출해 보시겠습니까 (ferrycast.kr)
```
```
완도 배편 앱 ferrycast.kr 지역 광고 제안 — ○○펜션
```
```
○○펜션 광고 제안 — 완도 배편·날씨 서비스 ferrycast.kr
```

### 본문

```
안녕하세요, ○○펜션 사장님.

완도 배편·날씨 정보 서비스 FerryCast(ferrycast.kr)를 운영하는 김신진입니다.

완도 페이지에 하루 100명 이상이 들어오고 있습니다. 배편 시간표 바로 아래에
지역 업체 광고 자리를 두고 운영하고 있는데, 완도 숙박업소를 우선으로 채우려고
합니다. ○○펜션에 제안드립니다.

월 5만원부터이며 배너 제작 비용은 따로 받지 않습니다. 월 단위라 원하실 때
중단하실 수 있습니다.

숙박업소를 먼저 떠올린 이유는 방문자가 그대로 겹치기 때문입니다. 저희 방문자는
완도로 들어오거나 완도에서 나가는 배 시간을 확인하는 분들입니다. 여행 일정을
짜는 단계에서 들어오고, ○○펜션이 있는 청산도는 저희 앱에서 배편을 가장 많이
확인하는 노선 중 하나입니다. 기상이 나빠 배가 끊기는 날에는 완도에서 하룻밤
묵을 곳을 찾는 분들이 몰립니다.

같은 광고 자리에 인천에서는 숙박업소인 36스테이가 게재 중입니다.

회신 주시면 ○○펜션 배너가 실제 화면에 어떻게 들어가는지 미리보기를 만들어
보내드리겠습니다. 사진 두세 장과 소개 한 줄만 주시면 배너는 저희가 만들고,
마음에 드실 때까지 수정해 드립니다. 게재 후에는 매달 노출 수와 클릭 수를
정리해 보내드립니다.

게재 예시는 아래에서 보실 수 있습니다.
ferrycast.kr/ads

김신진
climaxna@naver.com
```

### 치환 항목

| 자리 | 내용 |
|---|---|
| `○○펜션` | 정확한 상호 (네이버 플레이스 표기 그대로) |
| `청산도` | 그 숙소가 있는 섬 — 보길도·소안도·노화도 등으로 교체 |
| `배편을 가장 많이 확인하는 노선 중 하나` | 청산도·소안/보길 라인은 사실. 편수가 적은 섬이면 이 문장은 빼기 |
| 36스테이 문단 | 부담되면 통째로 삭제 가능 (없어도 메일은 성립한다) |

## 발송 시 주의

- **한 통씩 개별 발송.** 참조(CC)·숨은참조(BCC) 일괄 발송은 절대 금지.
- 상호를 제목·본문에 넣었는지 **발송 직전 반드시 확인**. 치환 실수가 가장 흔한 사고다.
- 발송 기록은 `영업_타겟리스트_현지업체.md` 표에 날짜·회신 여부로 남긴다.
- 회신이 오면 인바운드 대응은 `지역광고_운영가이드.md` 참고.

## 타이밍

숙박업은 특산물(명절)과 성수기가 다르다.

| 시기 | 판단 |
|---|---|
| 봄 (3~4월) | 청산도 유채·슬로길 시즌 직전 — **최적** |
| 초여름 (5~6월) | 여름 성수기 직전 — **최적** |
| 한여름 (7~8월) | 이미 예약이 차서 광고 필요를 못 느낀다 |
| 가을 (9~10월) | 가을 여행 시즌 직전 — 양호 |
| 겨울 (11~2월) | 비수기라 예산을 줄인다 |
