# 완도 특산물 업체 아웃바운드 영업 가이드

> 운영자가 완도에 상주하지 않는 조건(경기 이천 거주·육아 병행)에서 **원격으로만** 광고주를 구하는 방법.
> 문의가 들어왔을 때의 대응은 `지역광고_운영가이드.md`(인바운드) 참고. 이 문서는 **먼저 연락하는** 경우다.

---

## 1. 왜 "온라인 판매업체"가 1순위인가

| 대상 | 원격 계약 | 광고 이해도 | 우선순위 |
|---|---|---|---|
| **전복·특산물 온라인 판매업체** | 쉬움 (이메일로 완결) | 높음 (이미 네이버 광고 집행 중) | **1순위** |
| 펜션·숙박 | 가능 (온라인 예약 운영) | 중간 | 2순위 |
| 식당·카페 | 어려움 (오프라인 장사) | 낮음 | 후순위 |

- 완도 전복 판매업체는 **스마트스토어·자사몰로 전국에 파는 온라인 사업자**다. 노출·클릭 개념을 알고, 얼굴 안 보고 이메일로 계약하는 것이 일상이다.
- 반면 동네 식당·카페는 만나서 신뢰를 쌓아야 계약된다 → **현재 조건에서 사실상 불가**.
- 군청 협업(QR 부착)이 무산되면 방문자는 전부 **온라인 유입**이다. 파는 상품이 "온라인 노출"이니 사는 쪽도 온라인 업체가 맞다.

---

## 2. 타겟 리스트 만들기 (완도 방문 불필요)

전부 집에서 검색으로 가능하다. 30~50곳이면 충분하다.

| 출처 | 찾는 법 |
|---|---|
| 네이버 스마트스토어 | "완도 전복", "완도 김", "완도 미역", "완도 다시마" 검색 → 판매자 상호·연락처 |
| 네이버 플레이스 | "완도 전복 직판장", "완도 수산물" |
| 완도군 공식 쇼핑몰·특산물 페이지 | 입점 업체 목록 |
| 수협·어촌계 온라인몰 | 완도군수협 등 |
| 쿠팡·11번가 | "완도 전복" 판매자명 → 자사몰 역검색 |

> **연락처는 공개돼 있다.** 통신판매업자는 상호·대표자·연락처·이메일 표기가 의무(전자상거래법)라, 상품 페이지 하단 "판매자 정보"에서 확인할 수 있다.

**리스트 항목**: 상호 / 담당자(있으면) / 이메일 / 판매 채널 / 주력 상품 / 발송일 / 회신여부

---

## 3. 타이밍 — 명절 시즌을 노린다 ⭐

전복·김은 **추석·설 선물 성수기**다. 이때 판매업체 광고 예산이 가장 크다.

- **접촉 시점: 명절 4~6주 전** (업체가 선물 시즌 준비를 시작하는 때)
- 추석이 9월 하순이면 **8월 중순~하순**이 골든타임
- 명절 지나고 연락하면 "다음 명절에 보자"로 밀린다

## 4. 콜드 메일 템플릿 (본 메일)

**제목**
```
완도 여행 준비하는 방문자에게 ○○ 전복을 알릴 수 있을까요? (ferrycast.kr 광고 제안)
```
※ 상호를 제목에 넣어야 스팸으로 안 보인다. 일괄 발송 티가 나면 열람률이 급락한다.

**본문**
```
안녕하세요, ○○ 담당자님.

완도 배편·날씨 정보 서비스 'FerryCast'(ferrycast.kr)를 운영하는 김신진입니다.

■ 연락드린 이유

 · 클릭당 과금이 아니라 월 정액이라 비용이 예측 가능합니다
 · 방문자 전원이 완도 관련 검색으로 들어온 분들입니다

■ 제안 내용
 · 게재 위치 : 배편 시간표 바로 아래 (이용자가 핵심 정보를 확인한 직후 자리)
 · 비용     : 월 5만원 (월 단위, 언제든 중단 가능)
 · 배너 제작 : 무료 (상품 사진 2~3장과 소개 한 줄만 주시면 됩니다)

관심 있으시면 회신 부탁드립니다. 원치 않으시면 회신 주시면 다시 연락드리지 않겠습니다.
```

### 이 메일이 작동하는 이유
- **규모를 먼저 솔직하게 깐다** — 온라인 셀러는 반드시 숫자를 묻는다. 숨기면 신뢰를 잃고, 먼저 밝히면 나머지 주장이 믿을 만해진다.
- **"작지만 정확한 타겟"으로 판다** — 대량 노출로는 절대 못 이긴다. 이길 수 있는 축(타겟 정확도·경쟁 없음·정액제)만 이야기한다.
- **첫 달 무료로 리스크를 0으로** — 결정 장벽을 없앤다. 사례 1건이 다음 영업의 무기가 된다.
- **수신거부 문구** — 법적 안전장치이자 예의. 오히려 신뢰를 준다.

## 6. 회신이 오면

1. **24시간 안에 답장** — 반응 속도가 신뢰다.
2. 첨부: 게재 위치 스크린샷 + Vercel Analytics 방문자 캡처 1장
3. 금액·기간은 `지역광고_운영가이드.md` §2 정책 그대로 (첫 달 무료 → 이후 월 3만원, 또는 월 5만원 정가)
4. **세금계산서를 요구할 가능성이 높다** (온라인 사업자라 비용 처리를 한다) → 사업자등록이 선결. 미등록 상태면 솔직히 밝히고 일정 협의.
5. 배너 제작: 상품 사진 2~3장 + 소개 한 줄 → 시안 B(사진형) 사용

## 7. 발송 시 주의

- **개별 발송한다.** 참조(CC)에 여러 업체를 넣거나 대량 일괄 발송은 스팸이자 역효과. 상호·주력상품을 한 줄이라도 맞춤화한다.
- **공개된 사업자 연락처로만** 보낸다(상품 페이지 판매자 정보 등).
- **수신거부 의사를 밝히면 즉시 리스트에서 제거**하고 다시 보내지 않는다.
- 영리 목적의 광고성 정보 전송은 정보통신망법 규제 대상이 될 수 있다. 대량 발송이 아닌 **개별 사업 제안** 형태를 유지하고, 수신거부 안내를 본문에 포함한다. 규모를 키우거나 반복 발송할 계획이면 사전에 관련 규정을 확인할 것.
- **없는 숫자를 만들지 않는다.** 실측치(완도 100+/포항 50/목포 30/인천 20)만 쓴다.

## 8. 실행 체크리스트

- [ ] 타겟 30곳 리스트업 (스마트스토어·플레이스·완도군 쇼핑몰)
- [ ] 사업자등록 여부 결정 (세금계산서 요구 대비)
- [ ] 메일 20~30곳 발송 (개별, 상호 맞춤)
- [ ] 1주 후 무응답 건에 팔로업 1회
- [ ] 회신 건 24시간 내 대응
- [ ] 첫 광고주 확정 시 → `LocalAdCard` 구현 + 월간 리포트 시작

> **기대치**: 콜드 메일 답신율은 통상 한 자릿수 %다. 30곳 보내 1~2곳 회신이면 정상이다.
> 첫 1곳만 만들면 그 사례로 다음 영업이 훨씬 쉬워진다.
