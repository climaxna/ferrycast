## 리스트 넓히는 법 (30곳까지)

위 10곳으로 시작하되, 답신율(보통 한 자릿수 %)을 감안하면 **20~30곳**이 안전하다. 추가 확보 경로:

1. **네이버쇼핑 검색** — "완도 전복", "완도 김", "완도 미역", "완도 다시마"
   → 상품 페이지 하단 **판매자정보**에 상호·대표·이메일·전화가 표기돼 있음(법적 의무)
2. **완도군 대표쇼핑몰 입점 업체** (wandofood.go.kr) → 업체명 검색 → 자사몰 찾기
3. **쿠팡·11번가** "완도 전복" → 판매자명 → 자사몰 역검색
4. **네이버 플레이스** "완도 전복 직판장", "완도 수산물"

> **주의**: 연락처는 반드시 **업체가 공개한 판매자정보**에서만 수집한다. 추측하거나 조합하지 말 것.
