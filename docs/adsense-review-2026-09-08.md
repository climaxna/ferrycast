# 애드센스 승인 준비: 4~7번 점검

점검일: 2026-09-08. 애드센스 재신청은 실행하지 않음.

## 4. 서비스 소개·개인정보 대표 주소 — 수정

- `/about` canonical: `https://ferrycast.kr/about`
- `/privacy` canonical: `https://ferrycast.kr/privacy`
- 루트 layout의 `/`를 상속하던 문제를 페이지 metadata에서 재정의.
- 로컬 실제 HTML에서 각각 확인. 공유 이미지·배편·날씨 API는 변경하지 않음.

## 5. 광고 안내 페이지 검색 설정 — 수정

- 지역별 `/{region}/ads`에 `/ads`와 같은 `noindex, follow` 적용.
- 로컬 HTML에서 `/ads`, `/incheon/ads`, `/mokpo/ads`, `/jeju/ads`, `/ulleung/ads` 확인.
- `/pohang/ads`는 기존 울릉도 경로 전환 이후 동일한 설정 확인.
- 운영 사이트맵은 HTTP 200, URL 53개이며 광고 안내 URL은 포함하지 않음.
- `robots.txt`는 일반 페이지 크롤링을 허용하고 `/api/`만 차단. noindex를 읽을 수 있도록 광고 페이지를 robots.txt로 차단하지 않음.
- noindex는 검색 결과 제외 지시이지 애드센스 심사 제외나 승인 보장 수단이 아님.

## 6. 광고·쿠키 안내 — 보강

- 이 사이트 및 다른 사이트 방문 기록을 바탕으로 Google과 제3자가 광고를 제공할 수 있음을 명시.
- Google 광고 개인 최적화 설정, 제3자 참여 광고업체 수신 거부 도구 연결.
- 개인화 거부가 모든 광고 제거·모든 수집 중단과 같지 않으며 브라우저·참여 업체에 따라 범위가 다름을 안내.
- 최근 수정일을 2026-09-08로 갱신.
- 기준: [Google AdSense 필수 콘텐츠 안내](https://support.google.com/adsense/answer/1348695?hl=en).
- 이번 변경은 안내 문구 보완이며 광고 계정 설정·동의 관리 기능이나 전체 법적 준수 여부를 검증한 작업은 아님.

## 7. 모바일·검색 수집 확인 — 일부 완료

### 확인한 것

- 390×844 모바일 크기에서 운영 완도·인천·목포·제주·울릉도 본문 표시 확인.
- 확인한 지역 화면에서 문서 가로 폭이 viewport를 초과하지 않음.
- 완도 청산도 상세 열기 → 하단 관광지 안내 링크 → `/tour/cheongsando` 이동 확인.
- 청산도 상세의 시간표·예약하기·이용 안내 렌더링 확인.
- 인천 전체 화면 캡처에서 지역 배너와 시간표의 영역 분리 확인.
- 수정한 개인정보 페이지의 모바일 본문·링크 표시 확인.
- 앱 설치 안내가 본문 위에 떠 있으나 닫기 동작 가능. 광고와는 별도 UI.
- 타입 검사 및 변경 파일 diff 검사 통과.

### 미완료 및 확인 범위

- Search Console 관리 화면에 접근하지 못함. 도메인 속성 URL도 소개 화면으로 이동하여 실제 색인 보고서·최근 크롤링일·Google 선택 canonical은 미확인.
- HTTP 200, 사이트맵 포함, canonical 정상은 실제 Google 색인 완료의 증거가 아님.
- 모바일은 데스크톱 브라우저의 크기 조정 검사이며 실제 Android/iOS 기기 전체 검증은 아님.
- 모든 항로·모든 광고 소재·광고 자동 게재 위치를 전수 검사하지 않음. 미송출 제3자 광고가 채워졌을 때의 배치는 미확인. 광고는 클릭하지 않음.
- API 데이터 정확도·결항 판정·날씨 통신 로직은 이번 작업 대상이 아님.

### 운영자가 Search Console에서 확인할 항목

1. `ferrycast.kr` 속성 → 색인 생성 → 페이지: 색인되지 않은 이유와 예시 URL 확인.
2. URL 검사: `/about`, `/privacy`, `/guide/ulleung-from-mukho`, `/tour/cheongsando`를 각각 확인. 최근 크롤링 시각과 사용자 선언/Google 선택 대표 URL을 비교.
3. 사이트맵: `https://ferrycast.kr/sitemap.xml` 제출 상태와 마지막 읽은 날짜 확인.
4. 광고 안내 URL의 noindex 제외는 의도한 상태. 이용 가이드·관광지의 제외 사유와 구분.
5. 수정 후 재수집 필요 여부를 판단하되, 색인 요청과 애드센스 승인 심사는 별개로 취급.

다음 확인에 필요한 자료: Search Console의 **페이지 색인 생성 보고서**, 위 대표 페이지 **URL 검사 결과** 화면. 계정 비밀번호·인증번호는 공유할 필요 없음.
